### Carousels (AT-D16) — **FAIL**

Tracks: `.products-grid.carousel` (services), `.projects-row` (projects).

| Viewport | scroll-snap | Track scrollable | `scrollBy(+320)` | `.pb-arrow[data-dir="1"]` click | `.pb-arrow[data-dir="-1"]` |
|----------|-------------|------------------|------------------|--------------------------------|---------------------------|
| 1440 | `x mandatory` | yes (svc Δ146px) | **no movement** (`scrollLeft` stays 0) | **no movement** | disabled at start |
| 375 | `x mandatory` | yes | **no movement** | **no movement** | disabled at start |

**Root cause (Chromium RTL):** carousel uses **negative `scrollLeft`** range (`0` → `-146`). `nb-carousel.js` applies mockup `data-dir` **verbatim** (`+320` for `data-dir="1"`). Positive `scrollBy` is a no-op; only **negative** delta scrolls (`scrollLeft` → `-146` verified manually).

**Impact:** “הקודם” / forward-in-content arrows never advance carousels; users must drag (touch) — not spec-compliant.
