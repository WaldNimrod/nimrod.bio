## שימוש

1. עברו בין העמודים בתפריט העליון (BCS · תוצרת · ייעוץ חממה · SFA).
2. בכל סקשן — הוסיפו הערות בשדה האדום (נשמר אוטומטית).
3. לחצו **העתק JSON הערות** והדביקו בצ׳אט team_100.

## section_id
