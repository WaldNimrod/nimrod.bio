- `border-inline-start/end`

### 4c. JavaScript (new file)

**File:** `assets/js/nav-drawer.js` (~80 lines)

Implements:
- Drawer open: toggle `.is-open` on `.nav-drawer` + `.nav-backdrop`; `aria-hidden=false`; `aria-expanded=true`; `document.body.style.overflow = 'hidden'`
- Drawer close: reverse; restore body scroll
- Keyboard: `Escape` key closes
- Focus trap: Tab + Shift+Tab cycle within drawer when open
- Focus management: open → focus first link in drawer; close → return focus to toggle
- Backdrop click: close
- (Optional) Touch swipe to close: if touchstart+touchend delta > 80px in close direction

**Progressive enhancement:** if JS fails, drawer is hidden and nav links remain accessible in the collapsed header. `<noscript>` fallback: show full nav (unhide existing desktop nav structure on mobile).

Enqueue in `functions.php`:
```php
wp_enqueue_script(
    'nb-nav-drawer',
    get_template_directory_uri() . '/assets/js/nav-drawer.js',
    array(),
    NB_THEME_VERSION,
    array( 'strategy' => 'defer', 'in_footer' => true )
);
```

### 4d. Responsive images

For every `get_the_post_thumbnail()` call that renders a hero image (T2 hero, T3 hero, T1 anchor card), upgrade to use `sizes` attribute:

```php
echo get_the_post_thumbnail( $post_id, 'full', array(
    'loading'       => 'eager',
    'fetchpriority' => 'high',
    'sizes'         => '(max-width: 640px) 800px, (max-width: 900px) 1280px, 1920px',
    'alt'           => esc_attr( get_the_title( $post_id ) ),
) );
```

Add image sizes registration in `functions.php`:
```php
add_image_size( 'nb-hero-mobile', 800, 9999, false );    // 800px wide
add_image_size( 'nb-hero-tablet', 1280, 9999, false );   // 1280px wide
// 'large' (1600px) continues to serve desktop
```

Note: existing uploaded images won't auto-regenerate. Requires `wp media regenerate --yes` via WP-CLI on dev, or manual re-upload. This is a D-1 prep step.

### 4e. Font optimization

In `functions.php` Google Fonts enqueue, update URL to add `&display=swap` and subset:

```php
wp_enqueue_style(
    'nb-google-fonts',
    'https://fonts.googleapis.com/css2?'
    . 'family=Assistant:wght@300;400;500;600;700;800'
    . '&family=Frank+Ruhl+Libre:wght@500;700;900'
    . '&family=JetBrains+Mono:wght@400;500'
    . '&display=swap'
    . '&subset=hebrew,latin',
    array(),
    null
);
```

Add `<link rel="preload">` in `header.php` for the two most-used weights:
```html
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
```

## 9. Risks

| Risk | Likelihood | Impact | Mitigation |
|---|---|---|---|
| `nav-drawer.js` focus trap conflicts with existing scripts | L | M | Test in isolation first; check existing JS for competing keydown listeners |
| Drawer `inset-inline-end` not supported on old Safari | L | L | Fallback: `right: 0` in addition to `inset-inline-end`; check Safari 14+ (minimum target) |
| `safe-area-inset-bottom` env() breaks on older Android | L | L | Use `@supports (padding-bottom: env(safe-area-inset-bottom))` guard (already in spec) |
| Image srcset sizes cause layout shift (CLS regression) | M | M | Add explicit `width` + `height` attrs to all `get_the_post_thumbnail()` output; add `aspect-ratio` CSS |
| Regenerating media thumbnails breaks existing featured images | L | H | Use WP-CLI `wp media regenerate --only-missing` to avoid re-processing existing sizes |
| FTP upload IP changes between sessions | M | L | Confirmed: uPress requires re-allowlisting on IP change. Use `--skip-ip-check` after manual update |
| RTL logical properties not supported in WP Block Editor context | L | L | All CSS targets frontend theme, not editor — no conflict |
