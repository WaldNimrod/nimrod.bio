## 4. T1 sections per world (Variant C)

Each of the 3 page-{slug}.php files is **near-identical** — only the `$world_slug` differs. Implementation strategy: one shared template-part `template-parts/t1-body.php` that takes `$world_slug` as arg, and 3 thin page templates that call it.

Recommended structure:

```php
// page-soil.php
<?php defined( 'ABSPATH' ) || exit;
get_header();
get_template_part( 'template-parts/t1-body', null, [ 'world' => 'soil' ] );
get_footer();
```

(Same for know, code.)

Then `template-parts/t1-body.php` reads `$args['world']` and queries CPTs per the world slug.

### Sections (per design §6.T1)

1. **Hero** — big world name (Frank Ruhl Libre, 11vw) + 3 dim echoes behind (Variant C signature) + intro paragraph
2. **§01 ליבה** — Lattice with anchor card (centered, double-width, dark) + 4 lat-side service cards (`SvcCard`)
3. **CDIP mini-diagram** — 3 circles + 3 intersection dots
4. **§02 גשרים** — 3 Bridge cards (signal=`seam`, locked)
5. **§03 פרויקטים** — 3 ProjCards with subtle rotations
6. **§04 פוסטים** — 2 columns of recent posts in this world

### Data queries

```php
$world  = 'soil'; // or know/code per page
$anchor = nb_get_anchor_service_for_world( $world );
$svcs   = nb_query_by_world( 'service', $world, 4 );        // 4 lat-side services (excluding anchor)
$projs  = nb_query_by_world( 'project', $world, 3 );        // 3 projects
$posts  = nb_query_by_world( 'post', $world, 4 );           // 4 recent posts (2-col × 2 rows or 4 in one col)
// Bridge cards: explicit list of bridges this world has
// soil: [soil×know, soil×code]
// know: [soil×know, know×code]
// code: [soil×code, know×code]
// Implement as nb_get_bridges_for_world( $world ) helper added to template-helpers.php
```

Add to `inc/template-helpers.php`:
```php
function nb_get_bridges_for_world( string $world ): array {
    $all = [
        [ 'a' => 'soil', 'b' => 'know', 'title' => 'ייעוץ × אדמה' ],
        [ 'a' => 'soil', 'b' => 'code', 'title' => 'אדמה × דיגיטל' ],
        [ 'a' => 'know', 'b' => 'code', 'title' => 'דיגיטל × ייעוץ' ],
    ];
    return array_values( array_filter( $all, fn( $b ) => $b['a'] === $world || $b['b'] === $world ) );
}
```
