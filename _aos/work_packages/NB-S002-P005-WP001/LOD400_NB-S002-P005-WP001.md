| T8 Static | `/about/`, `/about/heritage/`, `/contact/` |

Viewports: **360 / 768 / 1280 / 1920** (mobile / tablet / laptop / desktop)

Per probe verify:
- No horizontal scroll (`scrollWidth ≤ innerWidth`)
- Shell nav usable (mobile drawer if implemented, else visible/wrapped)
- Footer columns reflow correctly
- No content overflow (no clipped text or hidden elements)

### 3.2 Lighthouse — full pass

Run on **8 sample URLs** (one per template type + 1 extra T4 post). Capture:
- Performance
- Accessibility
- Best Practices
- SEO

Targets: Performance ≥85, A11y ≥95, BP ≥90, SEO ≥85 (acknowledge dev's noindex caps SEO; main goal is non-SEO ≥ targets).

Use **HTTPS** with `--ignore-certificate-errors` flag (dev cert expired).

### 3.3 RTL bidi audit

Chrome + Safari + Firefox on each of:
- `/` (T7)
- `/blog/` (T5)
- `/services/produce/` (T2 with Hebrew labels mixing English brand terms)
- `/blog/יום-בגינה/` (T4 with Hebrew title)
- `/contact/` (T8 form with chips)

Look for:
- LTR escape (Hebrew word rendered LTR by mistake)
- Mirrored visuals (icons should NOT auto-mirror)
- Numeric / punctuation positioning (Hebrew numerals + colons)
- Mixed-direction inline content (e.g. brand "SFA" inside Hebrew sentence)
