## §1 · Objective

Remediate site-wide accessibility defects so the V200 site reaches **WCAG 2.1 AA** on its rendered pages, measured by two independent tools (axe-core + Lighthouse). All edits land in **module CSS (`assets/css/*.css`) and template-parts / templates only** — **no inline styles, no overrides layer, no edit to LOCKED `system.css` tokens.** Both super-locks honored in every byte changed (incl. alt/aria/comments).

**Root cause of contrast (the dominant defect):** the three "light" world tokens and the spark accent fail AA for **normal-size text on paper** —
`--w-soil #6a8a3a`=3.56 · `--w-know #c46a3e`=3.45 · `--w-code #2d8a8c`=3.69 · `--spark #d23a2e`=4.31 (all <4.5). The "deep" variants all pass (`--w-soil-deep`=7.86 · `--w-know-deep`=5.36 · `--w-code-deep`=6.69). Since `system.css` is LOCKED, the fix is to point **text/solid-chip/CTA** uses at the **deep** variant in the consuming module rules — not to change any token.

## §3 · Remediation plan (by pattern — each value pre-verified, see §6 table)

> All target ratios verified in `docs/qa/cdp/contrast_verify.mjs`. Decorative elements (chip dots, borders, icon SVGs) are AA-exempt and unchanged — only **text** and the **surface behind text** are touched.

**Contrast (serious):**
- **P1 — Terracotta/teal CTAs deepen.** Rest-state CTA backgrounds `var(--w-know)`→`var(--w-know-deep)` and `var(--w-code)`→`var(--w-code-deep)`. Rest now matches the *existing* hover shade. Files: `t7.css` (`.hp-btn-primary`), `t2.css` (`.hero-cta.primary`, `.primary.free`), `t8.css` (`.form-submit`, `.media-kind` text-CTA), `shell.css` theme-local `.btn-primary` (covers the LOCKED `system.css` base used by `page-about`).
- **P2 — Solid world chips deepen.** `t2.css`/`t3.css` `.wc` solid fills `--w-soil/know/code`→ deep variants (white text now ≥5.9).
- **P3 — `.scope.venture` deepen.** `t1.css`/`t7.css` `.scope.venture` background `--w-soil`→`--w-soil-deep`.
- **P4 — World chips on dark/colored surfaces.** Ghost/solid chips inside dark cards (`.flow-typo` blog teaser) and world-tinted hero tags get a legible light treatment (`--paper` text + translucent-paper border) instead of deep-on-dark.
- **P5 — WhatsApp green.** `#1f8a4c`→`#187a42` (white text 4.38→5.38); hover `#15703a`.
- **P6 — Spark on dark.** New theme-local `--spark-on-dark: #e8645a` (5.08 on ink) for the 3 dark-background spark emphases (`.shell-foot .unless em`, `.unless-inline`, `.unless-lockup .he em`). Spark in *large* headings (≥18.66px) already passes as large text — untouched.
- **P7 — Spark stamp text on paper.** New theme-local `--spark-on-paper: #c22f25` (5.07 on paper) for `.stage-stamp` seeking/pilot **text** (border + pulsing dot stay `--spark`). Files: `components.css`, `t1/t2/t3/t7.css`.
- **P8 — Muted greys.** Footer `.bottom`/`.manifesto .light .num` `rgba(paper,.45)`→`.55`; `.unless-lockup .src` `.42`→`.55`; contact `.opt` `opacity .7`→`.85`.
- **P9 — Transparent nav over hero (`.atop`).** Scrim `rgba(18,17,15,.5)`→`.72` (light nav text 3.45→7.24); add `.atop .shell-mark small` light color.

**Heading-order (moderate):**
- **H1 — Footer column labels** `<h6>`→`<h2>` (`shell-footer.php` + `.shell-foot .cols h6` selector). Removes the skip that recurs on **every** page (the bulk of the 24).
- **H2 — Archive card titles** `<h3>`→`<h2>` on `/projects/` & `/services/` (cards are the primary content under the page `<h1>`).
- **H3 — Sub-headings that skip** `<h4>`→`<h3>`: home §06 recent-posts cards, about principle-tiles, single-project "related", single-post aside, blog flow-brief. Contact: form `<h3>`→`<h2>` + cards `<h4>`→`<h3>`.

**ARIA / landmarks:**
- **A1 — `aria-hidden-focus`.** Mobile nav-drawer (`aside#nav-drawer[aria-hidden=true]`) contains focusable links at desktop. Drawer links get `tabindex=-1` while closed (managed by `nav-drawer.js`) or `inert` — focus removed when hidden.
- **A2 — duplicate/non-top-level `main`.** Archives render a nested/second `<main>` → collapse to one top-level `<main>`.
- **A3 — `complementary` not top-level.** Contact/single-post `<aside>` nested under non-body landmark → ensure top-level or `role` adjusted.
- **A4 — search `page-has-heading-one`.** Search results template gets a visible/`sr-only` `<h1>`.
