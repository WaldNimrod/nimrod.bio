## 4. T2 Service template (`single-service.php`)

### Sections per design §6.T2

1. Breadcrumb: בית › עולם(ות) › פעילות — use `nb_breadcrumb()`
2. **Hero** — single (1 world) OR bridge (2 worlds with stripe + seam). Selection via `count( nb_meta_array($id, 'worlds') )`.
3. **Heritage strip** — ONLY for service with slug `produce` — link to `/about/heritage/`. Use template-part `t2-heritage-strip.php`.
4. Meta strip — 4 facts from `_nb_meta_strip` JSON
5. §01-03 — `template-parts/t2-three-col.php` rendering who/how/what from `_nb_sections` JSON
6. SFA-specific: Origin flow (3 numbered steps) — ONLY for slug `sfa` — render inline in `single-service.php` with `if ( get_post()->post_name === 'sfa' )`
7. §04 פרויקטים — projects from `_nb_linked_projects`
8. §05 פוסטים — `_nb_related_posts`
9. Final CTA — 2 buttons (form + WhatsApp from `_nb_cta_whatsapp_href`)

### Per-instance variations (from design §6.T2)

| service slug | bridge? | CTA primary | CTA hint |
|---|---|---|---|
| produce | NO (soil only) | "הצעת מחיר" (know color) | "תגובה תוך 48 שעות" |
| consulting-hydro | YES (soil×know) | "הצעת מחיר" (know color) | "פגישת היכרות חינם" |
| sfa | YES (soil×code) | "הצטרף לקהילה" (code color) | "ללא תשלום" |

These are seeded via REST POST in §7.

## 6. Hero variants for T2 (bridge vs single)

```php
$worlds = wp_get_post_terms( get_the_ID(), 'world', [ 'fields' => 'slugs' ] );
$is_bridge = count( $worlds ) === 2;
get_template_part( 't2-hero', null, [
    'worlds'    => $worlds,
    'is_bridge' => $is_bridge,
    'title'     => get_the_title(),
    'lede'      => nb_meta( get_the_ID(), 'lede' ),
] );
```

In `t2-hero.php`:
```php
<?php if ( $args['is_bridge'] ): ?>
    <div class="t2-hero bridge-hero">
        <div class="bridge-stripe seam"></div>
        <div class="bridge-worlds">
            <?php echo nb_world_chip( $args['worlds'][0] ); ?>
            <span>×</span>
            <?php echo nb_world_chip( $args['worlds'][1] ); ?>
        </div>
        ...
    </div>
<?php else: ?>

        <?php echo nb_world_chip( $args['worlds'][0] ?? 'soil' ); ?>
        ...
    </div>
<?php endif; ?>
```
