### ToC generation

Auto-generated from `<h2>` elements in `the_content()`. Implement via:
- PHP regex on rendered content to extract h2 IDs/labels
- OR JS that runs on DOMContentLoaded and populates the ToC

Recommend: PHP regex (no JS dependency, no flash-of-empty-ToC):

```php
function nb_extract_toc( string $content ): array {
    preg_match_all( '#<h2[^>]*id="([^"]+)"[^>]*>(.+?)</h2>#', $content, $matches );
    $items = [];
    foreach ( $matches[1] as $i => $id ) {
        $items[] = [ 'id' => $id, 'label' => strip_tags( $matches[2][ $i ] ) ];
    }
    return $items;
}
```

Add `nb_extract_toc()` to `inc/template-helpers.php`.

## 5. T5 Blog index template (`home.php`)

WordPress uses `home.php` for the posts archive when site uses `/blog/%postname%/` permalinks and the homepage is a separate static page. Since we use `front-page.php` for the home and posts live at `/blog/`, WordPress will route `/blog/` to `home.php` automatically.

### Sections per design §6.T5

1. Header — "בלוג" giant title + lede + stats
2. Filter bar (sticky):
   - 3 world chips (multi-select) — `t5-filter-bar.php`
   - View toggle: `flow` (default) | `grid`
   - Live count + reset button
3. **Default view: flow** — editorial 6-col grid, `grid-auto-flow: dense`
4. **Alt view: grid** — uniform 3-col with featured post on top
5. Empty state — "אין פוסטים תחת הסינון הנוכחי. נקה סינון →"

### Flow variants (7 styles per post)

The `flow_style` taxonomy assigns one of 7 layouts to each post:

| flow_style | span | description |
|---|---|---|
| `lead` | span 6 (full row), horizontal | Image + lead text side by side |
| `wide` | span 4 | Image left, text right |
| `tall` | span 2 × 2 rows | Vertical, image on top |
| `typo` | span 3, dark bg | Typography only, no image |
| `quote` | span 3, paper-2 bg | Pull-quote styling |
| `feature` | span 3 | Standard featured card |
| `brief` | span 2, compact | Image + title only |

`template-parts/t5-post-flow.php` is one file with a `switch ($style)` rendering each variant. Each variant maps to a CSS class `.post-flow-{style}`.

### Filtering

URL params: `?world=soil,know&view=flow`

Server-side filtering in `home.php`:

```php
$world_filter = isset( $_GET['world'] ) ? explode( ',', sanitize_text_field( $_GET['world'] ) ) : [];
$view         = ( $_GET['view'] ?? 'flow' ) === 'grid' ? 'grid' : 'flow';

if ( ! empty( $world_filter ) ) {
    $world_filter = array_intersect( $world_filter, array_keys( nb_get_worlds() ) );
    set_query_var( 'tax_query', [
        [
            'taxonomy' => 'world',
            'field'    => 'slug',
            'terms'    => $world_filter,
            'operator' => 'IN',
        ],
    ] );
}
```

JS (`assets/js/t5-filter.js`) handles client-side filter chip clicks → updates URL → reloads. Pure URL-driven; no AJAX required for V200.

```js
// Pseudo:
document.querySelectorAll('.filter-chip[data-world]').forEach(chip => {
    chip.addEventListener('click', e => {
        const w = chip.dataset.world;
        const url = new URL(location.href);
        const current = (url.searchParams.get('world') || '').split(',').filter(Boolean);
        const next = current.includes(w) ? current.filter(x => x !== w) : [...current, w];
        if (next.length) url.searchParams.set('world', next.join(','));
        else url.searchParams.delete('world');
        location.href = url.toString();
    });
});
```
