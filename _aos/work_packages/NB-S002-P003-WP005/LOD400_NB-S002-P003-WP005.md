### Form handler (`inc/contact-form-handler.php`)

```php
<?php
defined( 'ABSPATH' ) || exit;

add_action( 'admin_post_nopriv_nb_contact_submit', 'nb_handle_contact_submit' );
add_action( 'admin_post_nb_contact_submit',        'nb_handle_contact_submit' );

function nb_handle_contact_submit() {
    if ( ! isset( $_POST['nb_contact_nonce'] ) || ! wp_verify_nonce( $_POST['nb_contact_nonce'], 'nb_contact_submit' ) ) {
        wp_safe_redirect( home_url( '/contact/?status=error' ) );
        exit;
    }

    // Honeypot — add hidden field "website" that bots fill; reject if non-empty
    if ( ! empty( $_POST['website'] ?? '' ) ) {
        wp_safe_redirect( home_url( '/contact/?status=ok' ) ); // pretend success
        exit;
    }

    $name    = sanitize_text_field( $_POST['name']    ?? '' );
    $email   = sanitize_email(      $_POST['email']   ?? '' );
    $phone   = sanitize_text_field( $_POST['phone']   ?? '' );
    $topics  = array_intersect( array_keys( nb_get_worlds() ), (array) ( $_POST['topics'] ?? [] ) );
    $message = sanitize_textarea_field( $_POST['message'] ?? '' );

    if ( ! $name || ! $email || strlen( $message ) < 20 ) {
        wp_safe_redirect( home_url( '/contact/?status=invalid' ) );
        exit;
    }

    $to      = get_option( 'admin_email' );
    $subject = sprintf( '[nimrod.bio · contact] %s', $name );
    $body    = "From:    $name <$email>\n";
    $body   .= "Phone:   $phone\n";
    $body   .= "Topics:  " . implode( ', ', $topics ) . "\n";
    $body   .= "\n" . $message . "\n";

    $sent = wp_mail( $to, $subject, $body, [ 'Reply-To: ' . $email ] );

    wp_safe_redirect( home_url( '/contact/?status=' . ( $sent ? 'ok' : 'error' ) ) );
    exit;
}
```

Add `require_once NB_THEME_DIR . '/inc/contact-form-handler.php';` to `functions.php` (necessary one-time edit by WP005).

## 7. Page bootstrap

Extend `inc/world-pages-bootstrap.php` (or create separate `static-pages-bootstrap.php` if cleaner) with:

```php
function nb_bootstrap_static_pages() {
    $about_id    = nb_ensure_page( 'about',    'על נמרוד',                0, 'publish' );
    $heritage_id = nb_ensure_page( 'heritage', 'הגינה של נמרוד · הסיפור', $about_id, 'publish' );
    nb_ensure_page( 'contact',  'צור קשר', 0, 'publish' );
    flush_rewrite_rules( false );
}
add_action( 'after_switch_theme', 'nb_bootstrap_static_pages' );
```

(Run alongside the world pages bootstrap from WP002-2.)

WordPress template hierarchy will auto-route:
- `/about/` → `page-about.php` (matched by page slug)
- `/about/heritage/` → `page-heritage.php`
- `/contact/` → `page-contact.php`
