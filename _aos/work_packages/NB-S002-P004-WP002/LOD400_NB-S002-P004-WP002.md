## 3. Locked decisions (per team_00 directives)

| Decision | Choice |
|---|---|
| Drops policy | **410 Gone** (`[G,L]`) — Google de-indexes faster; no SEO juice for retired URLs |
| .htaccess scope | **Additive block** delimited by `# AOS-V200-redirects-START` / `# AOS-V200-redirects-END` — never replace full file |
| Sitemap source | **Yoast SEO** — install on dev, regenerate via `POST /wp-json/yoast/v1/sitemap_index?regenerate=true` (or admin trigger fallback) |
| Drops in sitemap | Auto-excluded — Yoast respects post deletion state; the 6 drop posts were never imported per P004-WP001 |
| Mechanism | `.htaccess` Apache rewrite (NOT a WP plugin, NOT MU plugin) — fastest, runs at edge before PHP |

### URL encoding rule

WordPress serves Hebrew slugs URL-encoded (`%d7%XX`). Apache RewriteRule matches the encoded form. Generator must:
1. Read `old_slug` (decoded Hebrew from JSON)
2. URL-encode → `%d7%XX...` form
3. Same for `new_url`

Use Python `urllib.parse.quote()` with `safe='/'`.

### `keep` rows (2): NOT in .htaccess

`shook` and `blog` page slugs stay identical → no rewrite needed. Apache leaves them alone, WP routes natively.

Idempotent: rerunning replaces only the AOS block; preserves uPress-managed sections (cache, security headers).

## 8. Yoast installation + sitemap

Install Yoast SEO on dev:

```bash
# Via WP-CLI (preferred):
curl -X POST -u "$WP_REST_USER:$WP_REST_APP_PASSWORD" \
  "$WP_REST_BASE_URL/wp/v2/plugins" \
  -H "Content-Type: application/json" \
  -d '{"slug":"wordpress-seo","status":"active"}'

# Then trigger sitemap regen — option A: Yoast REST
curl -X POST -u "$WP_REST_USER:$WP_REST_APP_PASSWORD" \
  "$WP_REST_BASE_URL/yoast/v1/sitemap_index?regenerate=true"

# Option B: visit URL once (forces lazy regeneration)
curl -sk "$UPRESS_DEV_URL_HTTP/sitemap_index.xml" > /dev/null
```

Verify sitemap contains all 22 migrated posts:
```bash
curl -sk "$UPRESS_DEV_URL_HTTP/post-sitemap.xml" | grep -c "<loc>" # expect ≥22
```

Yoast configuration: defaults are fine; XML sitemap on, robots.txt managed by Yoast.
