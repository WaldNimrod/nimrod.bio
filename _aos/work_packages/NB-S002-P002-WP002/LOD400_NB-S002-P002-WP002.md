# LOD400 — NB-S002-P002-WP002 — CPTs + taxonomies + meta boxes (native)

## 1. Mission (one line)

Register the data layer of the new site — two custom post types (`service`, `project`) with all fields from design §3, two taxonomies (`world`, `flow_style`), native admin meta boxes for editing, REST API exposure for agent publishing, rewrite rules for `/services/{slug}/` and `/project/{slug}/`, and bootstrap of the 4 world pages so the nav stops 404-ing.

**Native code only. No ACF, Meta Box, Pods, or CPT-UI** (per team_00 decision Q5=D).

## 2. Inputs

- LOD400 of WP002 (theme skeleton, COMPLETE) — `_aos/work_packages/NB-S002-P002-WP001/LOD400_NB-S002-P002-WP001.md`
- CPT field specifications: `sources/team_35_design_package/_handoff/00-HANDOFF-claude-code-110.md` §3 (lines documenting `CPT: service` and `CPT: project`)
- Taxonomy specifications: same handoff §3 — `world` (soil/know/code) on `[service, project, post]`; `flow_style` (lead/wide/tall/typo/quote/feature/brief) on `[post]`
- URL patterns: handoff §2 — services `/services/{slug}/`, projects `/project/{slug}/`, worlds `/world/{slug}/`, posts `/blog/{slug}/`
- Theme already active on dev: `nimrod-bio-2026` v0.1.1

## 4. Decisions locked at LOD400

| Decision | Choice | Rationale |
|---|---|---|
| Field storage | `_nb_*` prefixed post_meta | Stays out of WP namespace; easy to query; REST-exposable |
| Editor for `story` (project rich text) | Native `wp_editor()` in meta box | TinyMCE/Block both work; design accepts either |
| Editor for `summary`, `lede`, `tagline` | Plain `<textarea>` / `<input>` | Single-paragraph text — no formatting needed |
| World page bootstrap | 1 parent page (`world`, hidden from nav) + 3 children (`soil`/`know`/`code`) | WP page hierarchy gives `/world/soil/` URL natively |
| Slug enforcement | WP defaults (`post_name`, sanitized) | No custom validation; let team_00 fix if collisions happen |
| Repeater fields (sections, meta_strip, outcomes) | **Fixed slots** — 3 for sections, 4 for meta_strip, 4 for outcomes | Spec calls out exact counts; fixed is simpler than dynamic JS |
| Gallery (project) | Comma-separated image IDs in single meta field | Avoid serialized arrays; easy to manage via media library picker |
| Conditional fields (seeking_note / legacy_of / linked_services) | Always render; label clarifies "(only shown when stage=… in templates)" | Avoid admin JS; UX cost = low; data cost = none |
| Permalinks | `/services/{slug}/`, `/project/{slug}/` (singular `project`, plural `services` per design §2) | Verbatim design |
| World page parent slug | `world` (singular, per design URL `/world/soil/`) | Matches Shell nav links from WP002 |
| REST exposure | `show_in_rest: true` for both CPTs + all `_nb_*` meta fields | Required for agent publishing |

```php
function nb_meta( int $post_id, string $key, $default = '' ) {
    $v = get_post_meta( $post_id, '_nb_' . $key, true );
    return $v === '' ? $default : $v;
}

function nb_meta_array( int $post_id, string $key ): array {
    $v = get_post_meta( $post_id, '_nb_' . $key, true );
    if ( is_array( $v ) ) return $v;
    if ( is_string( $v ) && $v !== '' ) return array_filter( array_map( 'trim', explode( ',', $v ) ) );
    return [];

function nb_sanitize_url_field( $url ): string {
    $url = trim( (string) $url );
    if ( $url === '' ) return '';
    if ( strpos( $url, 'wa.me/' ) === 0 || strpos( $url, 'mailto:' ) === 0 || strpos( $url, '/' ) === 0 ) return $url; // relative or known schemes
```

### 5.5 `inc/meta-registration.php`

Register every meta key with `register_post_meta()` for REST exposure. This is the canonical way to expose CPT fields to the REST API and Gutenberg.

```php
<?php
defined( 'ABSPATH' ) || exit;

add_action( 'init', function () {
    $string_meta = [
        'auth_callback' => function () { return current_user_can( 'edit_posts' ); },
        'show_in_rest'  => true,
        'single'        => true,
        'type'          => 'string',
    ];
    $bool_meta = [ 'auth_callback' => $string_meta['auth_callback'], 'show_in_rest' => true, 'single' => true, 'type' => 'boolean' ];
    $array_meta = [
        'auth_callback' => $string_meta['auth_callback'],
        'show_in_rest'  => [ 'schema' => [ 'type' => 'array', 'items' => [ 'type' => 'string' ] ] ],
        'single'        => true,
        'type'          => 'array',
    ];

    // ── service ──
    foreach ( [ 'tagline', 'lede', 'service_type', 'stage', 'cta_label', 'cta_whatsapp_href', 'is_anchor_for_world' ] as $key ) {
        register_post_meta( 'service', '_nb_' . $key, $string_meta );
    }
    register_post_meta( 'service', '_nb_is_free', $bool_meta );
    foreach ( [ 'linked_projects', 'related_posts' ] as $key ) {
        register_post_meta( 'service', '_nb_' . $key, $array_meta );
    }
    // sections — fixed 3 slots: who/how/what — stored as JSON string for simplicity
    register_post_meta( 'service', '_nb_sections', $string_meta );
    register_post_meta( 'service', '_nb_meta_strip', $string_meta ); // JSON string

    // ── project ──
    foreach ( [ 'scope', 'stage', 'year', 'location', 'duration', 'summary', 'seeking_note', 'legacy_of' ] as $key ) {
        register_post_meta( 'project', '_nb_' . $key, $string_meta );

    foreach ( [ 'linked_services', 'gallery', 'more_projects_ids' ] as $key ) {
        register_post_meta( 'project', '_nb_' . $key, $array_meta );

    register_post_meta( 'project', '_nb_outcomes', $string_meta ); // JSON string — 4 slots
```

```php
add_action( 'save_post_service', function ( $post_id ) {
    if ( ! isset( $_POST['nb_service_nonce'] ) || ! wp_verify_nonce( $_POST['nb_service_nonce'], 'nb_save_service_meta' ) ) return;
    if ( defined( 'DOING_AUTOSAVE' ) && DOING_AUTOSAVE ) return;
    if ( ! current_user_can( 'edit_post', $post_id ) ) return;

    $in = $_POST['nb'] ?? [];

    foreach ( [ 'tagline', 'lede', 'cta_label' ] as $k ) {
        update_post_meta( $post_id, '_nb_' . $k, sanitize_text_field( $in[ $k ] ?? '' ) );
    }
    update_post_meta( $post_id, '_nb_service_type', in_array( $in['service_type'] ?? '', array_keys( nb_get_service_types() ), true ) ? $in['service_type'] : 'service' );
    update_post_meta( $post_id, '_nb_stage',        in_array( $in['stage'] ?? '',        array_keys( nb_get_stages() ),        true ) ? $in['stage']        : 'live' );
    update_post_meta( $post_id, '_nb_is_free',      ! empty( $in['is_free'] ) ? 1 : 0 );
    update_post_meta( $post_id, '_nb_cta_whatsapp_href', nb_sanitize_url_field( $in['cta_whatsapp_href'] ?? '' ) );
    update_post_meta( $post_id, '_nb_is_anchor_for_world', in_array( $in['is_anchor_for_world'] ?? '', array_keys( nb_get_worlds() ), true ) ? $in['is_anchor_for_world'] : '' );

    // JSON-bound fields — store as-is after json_decode/encode round-trip for safety
    foreach ( [ 'sections', 'meta_strip' ] as $k ) {
        $raw = wp_unslash( $in[ $k ] ?? '' );
        $decoded = json_decode( $raw, true );
        update_post_meta( $post_id, '_nb_' . $k, $decoded === null ? $raw : wp_json_encode( $decoded, JSON_UNESCAPED_UNICODE ) );
    }

    // Comma-list arrays
    foreach ( [ 'linked_projects', 'related_posts' ] as $k ) {
        $list = array_filter( array_map( 'sanitize_title', array_map( 'trim', explode( ',', $in[ $k ] ?? '' ) ) ) );
        update_post_meta( $post_id, '_nb_' . $k, $list );
    }

    // worlds (taxonomy)
    $worlds = array_values( array_intersect( array_keys( nb_get_worlds() ), (array) ( $_POST['nb_worlds'] ?? [] ) ) );
    wp_set_object_terms( $post_id, $worlds, 'world', false );
} );
```

### 5.8 `inc/world-pages-bootstrap.php`

Idempotent: create parent `world` page + 3 children (`soil`, `know`, `code`) on theme activation if absent.

```php
<?php
defined( 'ABSPATH' ) || exit;

add_action( 'after_switch_theme', 'nb_bootstrap_world_pages' );

function nb_bootstrap_world_pages() {
    // 1. Parent: 'world' (hidden from menus — only exists to enable child URL routing)
    $parent_id = nb_ensure_page( 'world', 'עולמות', 0, 'private' ); // 'private' = not publicly listed in archives, but URL still resolves
    if ( ! $parent_id ) return;

    // 2. Children: soil / know / code (public)
    foreach ( nb_get_worlds() as $slug => $label ) {
        nb_ensure_page( $slug, $label, $parent_id, 'publish' );
    }

    // 3. Flush rewrites once
    flush_rewrite_rules( false );
}

function nb_ensure_page( string $slug, string $title, int $parent_id, string $status ): int {
    $existing = get_page_by_path( $parent_id ? "world/$slug" : $slug, OBJECT, 'page' );
    if ( $existing ) return (int) $existing->ID;
    return (int) wp_insert_post( [
        'post_title'   => $title,
        'post_name'    => $slug,
        'post_status'  => $status,
        'post_type'    => 'page',
        'post_parent'  => $parent_id,
        'post_content' => '<!-- world page placeholder — T1 template (WP003-P003-WP002) will render dynamic content -->',
    ] );
```
